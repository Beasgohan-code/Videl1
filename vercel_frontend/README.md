# Videl1 Vercel front door

This Vercel project proxies the Studio (`/app` and assets) and `/api/v1/*` to the
explicitly selected Render backend. It does not start the Telegram bot or run
background work on Vercel. The UI assets are served by Render through Vercel,
not independently built on Vercel, so their version stays aligned with the API.
The classic `/admin` link redirects directly to Render.

The backend URL in `vercel.json` is a non-secret deployment setting. Change it
only after explicitly choosing the intended Videl1 backend. Never put tokens,
sessions or credentials in the URL or in this repository. Deployments made from
this configuration can affect the selected backend; use an isolated test bot and
MongoDB for testing. Do not assume a preview is isolated just because its Vercel
URL is different: it shares the configured Render backend and its data.

This setup is not a production-readiness claim. The tenant isolation, operations,
authentication, proxy-aware rate limiting, storage durability and security gaps
in the root TODO.md remain. Vercel/Render request, response and timeout limits may
prevent large uploads, downloads and long-running operations; these have not been
validated. Telegram links generated by the bot may still point to Render.
