The listener is best-effort and opt-in by saving a filter. Per-group read/reply throttles, a shared read token bucket, concurrency and memory caps, timeouts and process-local replay checks can skip messages. These controls are not distributed or durable and reset/evict; Telegram privacy mode can prevent delivery. In-flight replies can still finish after filter removal. Every eligible ordinary group message can incur a bounded settings lookup even where no filters are configured. Configuration updates use single-document version CAS; restore/external writers can break its assumptions. Responses are retained through profile switches and soft-deletion and can appear in administrator backups.
